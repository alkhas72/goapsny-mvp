# Бриф для Codex: опытная ветка GoApsny по итогам изучения карт

Дата: 2026-10-18. Слой 03, GoApsny. Заказчик и Арбитр — Алхас. Автор брифа — Claude.

## Задача
Собрать опытную ветку текущего интерфейса GoApsny. В неё перенести элементы, найденные при изучении Google Maps, Яндекс Карт, Apple Maps, 2ГИС, AccessNow, Wheelmap, Organic Maps и OsmAnd. Результат — живая ссылка Vercel preview на телефоне. По ней Алхас посмотрит и оценит, как интерфейс выглядит и работает с этими элементами.

Три направления, по слову Алхаса:
- убрать то, что не нужно;
- добавить то, что необходимо;
- переосмыслить функционально.

Слово Алхаса от 18.10 снимает стоп «прототип не строить» из `.ui-craft/spec.md`, но только для этой опытной ветки.

## Порядок
1. **Кросс-аудит списка (до кода).** Прочитать `goapsny-takeaways.md` и `rea-vs-plain.md` в этой папке. По каждому пункту из раздела «Что делать» ниже ответить одной строкой: беру, меняю (как) или не беру (почему). Добавить своё, если видишь лучше. Ответ — файлом `codex-audit.md` в этой папке, в своей ветке. Слепого согласия не нужно.
2. **Сборка.** Ветка `feat/benchmark-prototype` от `origin/main`, один worktree. Режим `ui-craft-first`, для логики `superpowers-lite` (AGENTS.md). Ширина экрана 375–390, мобильный вид — первичный.
3. **Показ.** Push ветки даёт Vercel preview. Для каждого изменения нужны снимки «было / стало» на мобильной ширине. Ссылку на preview сделать доступной Алхасу без входа в Vercel (Share → Create link). Предупредить, если это не получится.
4. **Отчёт.** Ссылка, снимки, список «что сделано / что не сделано и почему», объявленный режим. Claude проверит результат и даст обратную связь.

## Что делать (предложение Claude; уточняется кросс-аудитом)

### Добавить
1. **Пустые слоты в карточке места.** У каждого признака доступности без данных (вход, туалет, парковка, места) строка «не проверено — сообщить». Тап ведёт в существующую «Сообщить об ошибке» с выбранным признаком. Источник: Google «Add hours»; через REA видна модель Google из четырёх признаков (вход, туалет, парковка, места).
2. **«Будьте первым».** Если в видимой области нет мест, показывать приглашение добавить место вместо пустоты. Кнопка ведёт в существующий путь добавления. Источник: AccessNow.
3. **Подборки.** Блок «Входит в подборки» в карточке места. Экран подборки — список мест с короткой заметкой у каждого, места подсвечены на той же карте, отдельного каталога нет. Для показа достаточно двух подборок на локальных данных: «Набережная без ступеней» и «Доступные кафе в центре». Источник: Яндекс «Входит в подборки», Google Lists, Apple Guides, «Гид» 2ГИС.
4. **Задания рядом.** Короткий список серых мест рядом с действием «сфотографировать вход» и кнопкой «не был здесь», чтобы пропустить место. Источник: экраны вклада Google, найденные REA: Missions, TodoPhoto, DidntGoHere, PostTripQuestions.
5. **Предупреждение о публичности.** Перед отправкой заявки одна строка: «Фото и описание увидят все». Источник: Organic Maps.
6. **Три крупные цветные кнопки** на шаге, где заявитель предлагает оценку. Источник: Wheelmap. Только форма кнопок: цвет на карте по-прежнему ставит волонтёр после проверки.

### Убрать
Пройти текущий публичный путь (старт, карта, карточка, добавление) на мобильной ширине и предложить, что убрать, со снимками. Ориентиры из изучения:
- требование входа до просмотра карты;
- старт не на Сухуме или слишком мелкий масштаб (в `docs/epoch3-inventory-maplibre.md` объявлен `DEFAULT_MAP_ZOOM=15`, а используется 13);
- повторяющиеся или пустые блоки;
- сырые технические названия.
Ничего не удалять «на всякий случай». Каждое удаление — пункт отчёта с причиной.

### Переосмыслить
- Как связаны карта, подборки и задания. Это нижние вкладки, чипы над картой или что-то третье? Нужно предложение с одним вариантом в сборке.
- Где в карточке место для «Входы» (Яндекс «Показать входы»). Сделать заготовку вида без новых данных или обосновать, почему пока не нужно.

### Не делать
- Маршрут для коляски: для него нет данных.
- Распознавание фото, размытие лиц, детектор: отложены решением Алхаса.
- Офлайн-очередь «не отправлено: N»: отдельная задача пути картографа.

## Ограничения
- Ничего не менять в `supabase/migrations/`, в схеме и в боевом Supabase. Контракт `docs/backend-contract-2026-06-01.md` не менять. Новые сущности (подборки, задания) живут в локальных данных фронта и в отчёте помечены как макет.
- Слияние в `main` не выполнять. Ветка опытная, её судьбу решит Алхас после показа.
- Решения из базы знаний не ломать: светофор + серый, цвет ставит только волонтёр, фото обязательно, канон карточки места `.ui-craft/spec.md` и `DESIGN.md`.
- Секреты не коммитить, `.env` не добавлять.
- Сбой или неоднозначность — остановиться и сообщить, не досочинять.
