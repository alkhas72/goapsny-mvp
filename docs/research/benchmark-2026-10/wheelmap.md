# Wheelmap.org (веб, мобильный вид 375×812; родное приложение не ставилось)

> Инструмент: REA (rea-agents 6.5.0) в этом разборе не использовался. Экраны сняты напрямую: родное приложение на эмуляторе Android на Mac mini (adb) или веб-версия в браузере.

Сухум (43.0015, 41.0153), без входа. Chrome на эмуляторе остановила проверка Cloudflare «Verify you are human» — не обходил. Официального APK нет, только магазины.

1. Первый экран: «Отмечайте и находите места, доступные для кресел-колясок… благодаря системе „светофора“»: зелёный — полностью, оранжевый — частично, красный — недоступно, серый — неизвестно; кнопка «ОК, поехали!». Места в Сухуме есть, из OSM (ШТАБ, «Вместе весело шагать», LAK — те же, что в Organic Maps), у всех «Неизвестный статус».
2. Карточка: название и тип («ШТАБ, Fast food»), вопрос «Насколько это место доступно для кресел-колясок?» и три крупные цветные кнопки «Полностью / Частично / Нисколько» (оценка в один тап), «Добавить изображения» с «Улучшите свою карму!», «Открыть в Maps app», «Открыть в OpenStreetMap», «Сообщить об ошибке».
3. Вклад: кнопки оценки не нажимались, чтобы не писать в реальные данные OSM; нужен ли вход при нажатии — не проверено. Меню: «Добавить недостающее место» → wheelmap.pro (отдельный сервис опросов организаций), «Поучаствуйте», «Новости», «ЧаВО», Events (маркеры событий картирования на карте, корпоративные волонтёрские выходы).
4. Путеводитель: каталога нет; есть Events и новости на news.wheelmap.org. Подборок нет.
5. Фильтры: «Все места» (статус и категории). Маршрутов для коляски нет; «Открыть в Maps app» передаёт точку другому приложению.

## Выводы
- Доступность — единственная тема; вклад сведён к одному тапу по трём цветам.
- Серый «неизвестно» сам просит оценки.
- В Сухуме всё серое: оценок ещё никто не ставил — первые можем поставить мы.
