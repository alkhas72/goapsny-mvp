# Сравнение сервисов — что видно на экранах

> Инструмент: экраны без REA (эмулятор или браузер); поправка про Apple Maps — по снимку REA 18.10. Полное сравнение — ../rea-pass/rea-vs-plain-2026-10-18.md.

Проверка: Google Maps — родное приложение (эмулятор Android, Pixel 6); Яндекс Карты, 2ГИС, AccessNow, Wheelmap, Apple Maps — веб; Organic Maps и OsmAnd — родные (см. ../organicmaps, ../osmand). Вход ни в один сервис не выполнялся, правки не отправлялись.

## Данные по Сухуму
- Google: подробные, подписи «Sokhumi».
- Яндекс: подробные, русские названия, местами абхазские улицы.
- 2ГИС: основа карты и «Город Сухум 4.2 (87 оценок)»; организаций не видно.
- AccessNow: не подтверждено («будьте первым»).
- Wheelmap: места из OSM, все «неизвестно».
- Apple: улицы подписаны (снимок REA 18.10), точек интереса нет.
- Organic Maps / OsmAnd: подробные (OSM), абхазские названия.

## Доступность в карточке места
- Google: блока нет. Яндекс: нет, но есть «Показать входы». 2ГИС, Apple: не проверено.
- AccessNow: вся тема сервиса, зелёные и красные пины.
- Wheelmap: три кнопки «Полностью / Частично / Нисколько».
- OsmAnd / Organic Maps: типа «пандус» нет; в OsmAnd сырые теги wheelchair.

## Как добавить / исправить
- Google: «Suggest an edit», «Add hours» — только после входа.
- Яндекс: «Исправить неточность», «Сообщить об ошибке», «Добавить фото».
- 2ГИС: «Добавить организацию».
- AccessNow: вход или приложение.
- Wheelmap: оценка кнопкой, «Добавить недостающее место» (wheelmap.pro), «Добавить изображения».
- OsmAnd: плагин, теги, вход через браузер. Organic Maps: «Add Place», форма, вход внутри приложения.

## Путеводитель / подборки
- Google: лента гидов «Latest in the area», списки Saved — на карте и в аккаунте.
- Яндекс: «Входит в подборки» внутри карточки места (редакционные «Подборка · N мест»), ведут на карту.
- 2ГИС: вкладка «Гид» в главном меню (не открывалась).
- AccessNow: каталоги городов и стран, категории, MapMissions.
- Wheelmap: Events и новости, каталога нет.
- Apple: раздел путеводителей.
- OsmAnd: «Travel guides (Beta)».

## Маршрут для коляски
Ни у кого нет отдельного режима. Google: «Wheelchair accessible» только в настройках общественного транспорта (для Сухума пусто), пешком «Mostly flat». Остальные: нет или не проверено.

## Побуждение к вкладу
Google — пустые слоты «Add hours», «Reported by 4 people». Яндекс — рейтинги, «Добавить фото». 2ГИС — «Добавить организацию». AccessNow — «Be the first to add a pin». Wheelmap — «карма», Events, светофор. Organic Maps — предупреждение о публичности.

## Не снято
Родные приложения Яндекса, 2ГИС, Wheelmap, AccessNow, Apple (APK только в магазинах, APKMirror закрыт Cloudflare); карточки организаций 2ГИС; фильтры AccessNow; «Гид» 2ГИС; карточки и «Report an Issue» Apple; нужен ли вход для оценки в Wheelmap.
