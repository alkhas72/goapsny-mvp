# Google Maps (Android, эмулятор Pixel 6, без входа в аккаунт)

> Инструмент: REA (rea-agents 6.5.0) в этом разборе не использовался. Экраны сняты напрямую: родное приложение на эмуляторе Android на Mac mini (adb) или веб-версия в браузере.

Версия: предустановленная в образе Android 15 (com.google.android.apps.maps). Геопозиция эмулятора: Сухум 43.0015/41.0153. Вход не выполнялся. Только то, что видно на экранах.

1. Первый экран: «Make it your map» — приглашение войти, SKIP в углу. Дальше карта Сухума с подписями «Sokhumi», грузинским шрифтом и латиницей, улицы с названиями (Ardzinba St, Lakoba St…), значки заведений, кнопка слоёв, «Search here», снизу вкладки Explore / Go / Saved / Contribute / Updates и лента «Latest in the area» с фото местных гидов (Local Guide). Данные по Абхазии подробные; абхазских названий нет (латиница, грузинский, у части мест русский).
2. Карточка места: «Столовая Эверест», 4.7 (96 отзывов), тип, цена, «Walking mode: 8 min», кнопки Directions / Start / Save / Share, фото. Вкладки OVERVIEW / MENU / REVIEWS / UPDATES / ABOUT. ABOUT: адрес, Plus Code, цена «Reported by 4 people», «Suggest an edit», «Claim this business», пустые слоты-приглашения «Add place's phone number / Add hours / Add website», блок «Features» с «Edit features»: структурированные признаки галочка/крестик по группам (Service options, Popular for, Offerings, Dining options, Amenities, Atmosphere, Crowd, Planning, Children). Блока «Accessibility» (вход без ступеней, туалет) у этого места нет, хотя «Has restroom» есть.
3. Добавить/исправить: «Suggest an edit» → «Sign in to suggest your change». Вкладка Contribute целиком — «Share your experiences, Sign in…». Без аккаунта Google правки невозможны.
4. Путеводитель: отдельного каталога без карты нет; роль гида играет лента «Latest in the area» (фото и посты местных гидов на Explore), списки «Saved» и вкладка Updates. Всё привязано к карте и к аккаунту.
5. Доступность в маршруте: пешком «Mostly flat» и «Steps» (шаги маршрута). Транспорт в Сухуме — только «Walk». В «Trip options» есть «Wheelchair accessible — Avoid stairs and prefer elevators», но только для общественного транспорта, которого для Сухума нет. Режима «коляска» среди авто / транспорт / пешком / велосипед нет.

## Выводы
- Данные по Сухуму богатые (фото, отзывы, часы), доступности нет.
- Вклад только через аккаунт Google.
- Пустые слоты «Add hours» — хороший приём побуждения к вкладу.
- «Features» с галочками — структурированные признаки, куда легла бы «вход без ступеней».
