# Organic Maps и OsmAnd: путь картографа и выводы для GoApsny

> Инструмент: Organic Maps пройден вживую на эмуляторе Android на Mac mini без REA. По OsmAnd REA 6.5.0 разобрал манифест APK и снимал экраны через adb (см. ../osmand/osmand-mapper-path-findings-2026-10-14.md).

Дата: 2026-10-14. Слой 03, GoApsny. Оба приложения пройдены живьём на эмуляторе Pixel 6 (Android 15) на Mac mini. Organic Maps версии 2026.09.29, OsmAnd 5.4.10. Ничего не отправлено в настоящую OSM: правка в Organic Maps сохранялась в авиарежиме, затем данные приложения стёрты до возврата сети.

Снимки (Organic Maps, 18 экранов) на Mac mini: `~/ai-cloude-agents/claude/research/organicmaps/`. Выводы по OsmAnd: [osmand-mapper-path-findings-2026-10-14.md](../osmand/osmand-mapper-path-findings-2026-10-14.md).

## Сравнение по шагам

| Шаг | Organic Maps | OsmAnd | Что делать в GoApsny |
|---|---|---|---|
| Первый запуск | Определяет место и предлагает «Скачать Абхазию?», карта в один тап | Без геопозиции ищешь карту сам, две записи «Georgia» отличаются только размером | Карта Сухума сразу, офлайн-пакет города одной кнопкой |
| Вход в добавление | «Меню → Добавить место в OSM», первый пункт | Нужно знать про плагин, включить его, найти «Действия» | Одна большая кнопка на карте (есть) |
| Где точка | Экран «поставь крест», карта сама приближается до зданий, подсказка одной фразой | Точка берётся с карточки места | Наш шаг 4 «перетащите пин ко входу» близок; добавить автоприближение до зданий |
| Форма | Готовые поля: название, адрес, часы, телефон, сайт, соцсети, переключатель Wi-Fi | Базовая вкладка и сырая таблица тегов, подсказка перекрывает поле значения | Готовые поля и ответы кнопками, никаких тегов |
| Типы про доступность | Нет: на «ramp» и «wheel» пусто, на «entrance» пещера и парковка. Честно пишет «Не нашли категорию?» и предлагает заметку волонтёрам | Нет: батут и пандус для машин | Свои типы: пандус, вход без ступеней, лифт, туалет для МГН; ответы «да / нет / частично / не знаю» |
| Публичность | Вверху формы «правки уходят в публичную базу OSM, личные данные не добавлять», перед отправкой «Отправить всем?» | Не предупреждает | Короткое предупреждение, что попадёт на общую карту, и что нельзя снимать лица |
| Сохранение | «Сохранить» означает сразу «отправить всем»; вход спрашивается в момент отправки | Сохраняет на телефоне, без явного «сохранено» | Явный экран «Сохранено на телефоне, отправится при сети» |
| Список своих правок | В меню не найден | Глубоко: Меню → Мои места → третья вкладка, значки без подписей | Счётчик «не отправлено: N» на карте и кабинет в одно касание |
| Вход | Встроен в приложение: логин, пароль, регистрация | Уводит в системный браузер | Вход через Telegram без ухода из приложения |
| Без сети | Статуса «не отправлено» не видно | Страница браузера «вы не в сети», затем снова вход | Своё сообщение и автоматическая отправка при появлении сети |

## Выводы

1. **Брать у Organic Maps**: минимум шагов, экран «поставь крест» с автоприближением, одна форма без тегов, честное предупреждение о публичности, вход внутри приложения.
2. **Брать у OsmAnd**: правки живут на телефоне до отправки. Это и есть наша офлайн-очередь.
3. **Чего нет ни у кого и что делает GoApsny нужным**: типы объектов про доступность с понятными ответами, явный статус «не отправлено», отправка без чужого аккаунта и с модерацией. Это наше главное отличие, его стоит держать в центре интерфейса.
4. **Быстрый путь**: «Не нашли категорию? Оставьте заметку» у Organic Maps и заметка OSM у OsmAnd подсказывают второй вход рядом с мастером: «Сообщить о барьере» одним полем и фото.

## Не проверено

- Отправка из OsmAnd после входа в OSM и её ошибка без сети: окно входа открыто и ждёт входа Арбитра.
- Поведение на реальном GPS: в эмуляторе геопозиция задаётся искусственно.
- iPhone: Xcode на Mac mini не установлен.

## Сверка с базой знаний (ais-obsidian, слой 03)

Сверено с `goapsny-analogues-master-table-2026-07-05.md` и `goapsny-level1-ux-walkthrough-2026-07-05.md`.

**Уже решено раньше, сегодня подтверждено живым прохождением:**
- Никакой регистрации в OSM для публики: вход через Telegram (антипаттерн №1 в базе; OsmAnd уводит в браузер, Organic Maps требует аккаунт OSM при отправке).
- Одна кнопка «Добавить локацию», ответы с «не знаю», без 20 чипов и сырых тегов.
- Статусы в «Мои заявки», автосохранение черновика.
- Атрибут «приставной пандус» (`ramp:portable`): ни в OsmAnd, ни в Organic Maps подходящих типов про доступность нет.

**Новое по итогам сегодняшнего прохождения:**
1. Подробная карта Абхазии из OSM занимает 13,9 МБ (Organic Maps, регион «Abkhazia»), её можно встроить в приложение сразу. В OsmAnd отдельного пакета нет, только «Georgia» на 149,9 МБ.
2. Экран «поставь крест» с автоприближением до зданий (Organic Maps) как образец для мини-карты с пином.
3. Короткое предупреждение «попадёт на общую карту, без лиц и личных данных» перед отправкой (Organic Maps).
4. Явный статус «не отправлено: N» на карте и своё сообщение при отсутствии сети: ни одно из двух приложений этого не делает, а для офлайн-очереди это ядро.
5. Режима маршрута «коляска» нет ни в OsmAnd на iPhone, ни на Android: машина, велосипед, пешком, автобус.
6. В данных OSM по Сухуму уже есть лестницы, переходы, светофоры, туалеты — их можно показывать слоем.
